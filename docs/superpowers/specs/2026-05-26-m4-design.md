# M4 Design Spec: EVM Internal Call Tracing

## 1. Goal

Parse EVM internal calls (CALL/DELEGATECALL/STATICCALL/CREATE/CREATE2) via `debug_traceTransaction` with `callTracer`, decode calldata against the ABI registry, and emit `Event(kind="call")` for each resolved internal call.

## 2. Scope

Four chunks:

| # | Deliverable | Key files |
|---|-------------|-----------|
| 1 | `debug_traceTransaction` RPC + `InternalCall` data structure | `core/chains/types.py`, `core/chains/evm.py` |
| 2 | `InternalCallParser` — recursive call tree → Events | `core/parser/internal_call.py` |
| 3 | ChainRunner integration + `trace_internal_calls` config | `apps/worker/chain_runner.py`, `core/config/models.py`, `apps/web/schemas.py` |
| 4 | E2E test (Anvil + proxy contract) + `m4-complete` tag | `tests/e2e/` |

## 3. Out of scope

- `prestateTracer` / state-diff analysis
- SELFDESTRUCT opcode tracking
- Solana internal CPI tracing (already handled by `stack_depth` in M2)
- Auth on management API (M5+)
- Events persistence / replay (M5+)

## 4. Detailed design

### 4.1 Chunk 1: `debug_traceTransaction` RPC + InternalCall

**Data structure.** New recursive dataclass in `core/chains/types.py`:

```python
@dataclass(frozen=True)
class InternalCall:
    type: str          # CALL, STATICCALL, DELEGATECALL, CREATE, CREATE2
    from_addr: str
    to_addr: str | None  # None for CREATE/CREATE2 (address is in output)
    value: int         # wei transferred
    gas: int
    input: str         # hex calldata
    output: str        # hex return data
    error: str | None  # revert reason if failed
    calls: list[InternalCall] = field(default_factory=list)
    # CREATE/CREATE2 specific
    created_address: str | None = None
```

**RPC integration.** `EvmAdapter` gains two methods:

- `trace_transaction(tx_hash: str) -> InternalCall | None` — sends `debug_traceTransaction` with `{"tracer": "callTracer", "tracerConfig": {"withLog": false}}`. Parses the nested JSON response recursively into `InternalCall`. Returns `None` if the debug namespace is unavailable (-32601 Method not found).
- `trace_block(number: int) -> list[InternalCall]` — traces all txs in a block. Tries `debug_traceBlockByNumber` first (Geth); falls back to per-tx `trace_transaction` if unavailable. Returns empty list on RPC error (graceful degradation).

**Retry.** Both methods wrap the RPC call in `retry_with_backoff(max_attempts=2, base_delay=1.0)` — tracing is expensive and a single timeout shouldn't drop the entire block.

### 4.2 Chunk 2: InternalCallParser

**New file** `core/parser/internal_call.py` with class `InternalCallParser(chain_id: str, registry: AbiRegistry)`.

**`parse(traces: list[InternalCall], block: Block) -> Iterable[Event]`** — for each `InternalCall` in the list (and recursively through `.calls`):

- **CALL/STATICCALL/DELEGATECALL:** Extract 4-byte selector from `call.input[:10]`. Look up via `registry.lookup_function_by_selector(selector)`. If found: decode calldata → emit `Event(kind="call", name=<fn_name>, contract=call.to_addr, args=<decoded>)`. If not found: skip (same policy as top-level `AbiCallParser`).
- **CREATE/CREATE2:** Emit `Event(kind="call", name="<create>", contract=call.created_address, args={"value": str(call.value)})`. No ABI decode — initcode is not a function call.
- **Failed calls** (`call.error is not None`): Skip — matches the existing convention (M1 `NativeTransferParser` skips `status=0` txs).

The parser does NOT replace `AbiCallParser` — it complements it. `AbiCallParser` handles top-level tx.input; `InternalCallParser` handles depth > 0. Both can fire for the same tx (top-level call + internal calls).

### 4.3 Chunk 3: ChainRunner integration

**Config field.** `SnapshotChain` gains `trace_internal_calls: bool = False`. DB column: `chains.trace_internal_calls` (nullable bool, default NULL → treated as False). API: `ChainCreate` gains optional `trace_internal_calls: bool = False`.

**Pipeline wiring.** In `ChainRunner._process_confirmed_block`, after the existing `self._evm_pipeline.run(block)`:

```python
if self._chain.trace_internal_calls and self._abi_registry is not None:
    traces = await self._adapter.trace_block(block.header.number)
    internal_parser = InternalCallParser(chain_id=self._chain.id, registry=self._abi_registry)
    for event in internal_parser.parse(traces, block):
        hits = [(sub, chans) for sub, chans in matcher.match(event) if chans]
        if hits:
            await notifier.dispatch(event, hits)
```

The `InternalCallParser` is instantiated per-block (stateless, cheap) rather than stored on the runner — avoids adding another field to the already-wide `__init__`.

**Solana path:** Unchanged. `trace_internal_calls` is EVM-only; Solana inner CPIs are already handled by `stack_depth` filtering in existing parsers.

### 4.4 Chunk 4: E2E test

**Fixture.** Deploy two contracts to Anvil:
1. `Target` — a simple contract with `function doTransfer(address to, uint256 amount)` that calls `to.call{value: amount}("")`.
2. `Proxy` — a contract with `function forward(address target, bytes calldata data)` that does `target.call(data)`.

**Test flow:**
1. API: create chain (trace_internal_calls=true) + subscription (match_kind="call") + HTTP webhook channel.
2. Call `Proxy.forward(Target.address, doTransfer.encode(recipient, amount))`.
3. Assert webhook receives an event with `name="doTransfer"` from the internal call (not just the top-level `forward` call).

**Anvil support.** Anvil supports `debug_traceTransaction` with `callTracer` natively — no special flags needed.

## 6. Dependencies

No new runtime dependencies. `debug_traceTransaction` is a JSON-RPC call over the existing `httpx` / `web3` transport.

## 7. Risks

- **RPC provider support.** Not all providers expose `debug_traceTransaction` (Infura doesn't; Alchemy does on paid plans; self-hosted Geth/Erigon do). The graceful fallback (return empty list) ensures the indexer doesn't crash, but users on unsupported providers get no internal call data. Document this in a README note.
- **Performance.** `debug_traceTransaction` is 10-100x slower than `eth_getBlockByNumber`. For high-throughput chains, tracing every block may lag behind tip. Mitigation: the feature is opt-in per chain (`trace_internal_calls=false` by default); operators enable it only for chains where they need internal call visibility.
- **Call tree depth.** Pathological contracts can produce deeply nested call trees (100+ levels). The recursive parser uses Python's call stack; depth > 1000 would hit recursion limit. Mitigation: cap recursion at 64 levels (log and skip deeper calls). In practice, EVM gas limits prevent trees deeper than ~50 levels.
